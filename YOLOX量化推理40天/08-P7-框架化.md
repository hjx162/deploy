# P7 · 框架化（D31–D35）

> [!info] 阶段定位
> 从“能跑的脚本”变成“能复现、能对比、能扩展的框架”。这一阶段做图优化、内存规划、Python API、benchmark suite 和文档。如果时间紧，P7 可以缩，但不要省掉 benchmark 和 README。

> [!note] 机器：任一（CUDA 集成建议留 N 卡）
> 图优化/内存规划/API/benchmark 可在 Mac 做（NumPy 后端）；CUDA 后端集成和性能数字回 N 卡机器验证。D35 结束前 push + tag `p7-done`。详见 [[11-双机Git工作流]]。

## 阶段目标

- 图级优化：常量折叠、死节点消除、算子融合。
- 内存规划：arena/池化、buffer 复用、权重预布局。
- Python API：`load_model` / `run`，错误处理。
- 一键 benchmark：NumPy / ORT / CUDA float / CUDA int8 对比。
- 文档和复现实验。

## 硬验收标准

- [ ] 一条命令跑完 benchmark，输出延迟/精度/显存表。
- [ ] Python API 可用：加载模型、跑单张图、返回检测结果。
- [ ] 图优化前后有对比数据，且结果不变。
- [ ] README 能让别人从零复现。
- [ ] 代码结构清晰：graph / ops / runtime / quant / cuda 分层。

## 前置条件

- P5/P6 至少有一个 GPU 版本可跑。
- 有一个稳定的测试输入和参考输出。
- 知道 CMake/Makefile、pybind11 基础（如果做 Python API）。

## 每日任务

### D31 · 图优化

- [ ] 常量折叠：initializer 参与的纯常量子图提前算掉。
- [ ] 死节点消除：只保留输出依赖的节点。
- [ ] 算子融合：Conv+Bias+SiLU、Conv+BN（如果需要）。
- [ ] 拓扑排序 + 内存生命周期标注。
- [ ] 优化前后输出对拍，确保数值不变。
- [ ] 记录每项优化的收益。

**完成标志**：优化后结果不变；有一张优化前后对比表。

### D32 · 内存规划

- [ ] 统计每个 tensor 的生命周期（首次使用/最后使用）。
- [ ] 实现简单的内存池/arena；复用不再需要的 buffer。
- [ ] 权重预转布局（如 NHWC、int8 打包），避免运行时转换。
- [ ] 记录峰值显存/内存。
- [ ] 动态 shape 先不做，明确写进非目标。
- [ ] 缓冲：补测试。

**完成标志**：峰值内存下降；没有 use-after-free。

### D33 · Python API

- [ ] 设计 API：`Model(path, backend="numpy"|"cuda")`、`model.run(image)`。
- [ ] pybind11 绑定 C++/CUDA（如果做 CUDA 后端）。
- [ ] 错误处理：模型不存在、shape 不对、CUDA 错误。
- [ ] 返回统一结构：boxes、scores、classes。
- [ ] 写 3 个示例：单图、批量、benchmark。
- [ ] 单测：API 能跑通，错误能抛清楚。

**完成标志**：别人用 5 行代码能跑一张图。

### D34 · Benchmark suite

- [ ] 统一输入尺寸、warmup、次数、统计方式（median/P90）。
- [ ] 对比：NumPy float、NumPy int8、ORT CPU、CUDA float、CUDA int8、TensorRT（如果有）。
- [ ] 指标：延迟、吞吐、显存、mAP/一致率、模型大小。
- [ ] 生成 Markdown 表格，自动写入 `docs/benchmark.md`。
- [ ] 记录测试环境（GPU/CPU/驱动/CUDA）。
- [ ] 检查可复现性：同一命令跑两次结果接近。

**完成标志**：一张完整、可复现的对比表。

### D35 · 清理 + 文档

- [ ] 目录结构整理：`src/graph`、`src/ops`、`src/runtime`、`src/quant`、`src/cuda`。
- [ ] 删除临时脚本/死代码；统一命名。
- [ ] README：安装、模型准备、运行、benchmark、已知问题。
- [ ] 架构图：graph → optimizer → executor → ops → backend。
- [ ] 缓冲：补测试或写复盘。

**完成标志**：新机器按 README 能跑通。
